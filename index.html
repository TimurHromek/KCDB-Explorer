About KCDB

Kirka Chat Database — API documentation and info

What is KCDB?

KCDB (Kirka Chat DataBase) is an independently operated database that logs public chat messages from Kirka.io. It is maintained by amcalledglitchy.dev.

About scraping: Please don't be a dick, if you want to get the entire db ask nicely (amcalledglitchy.dev discord or me@amcalledglitchy.dev email) and I'll probably dump the db if I'm in a good mood.

API Base URL

kcdb.amcalledglitchy.dev

Endpoint: /api/messages

Retrieve a list of messages based on various filters. Results are always returned in descending order (newest messages first). Cache Duration: 5 seconds.

Query Parameters

Parameter Type Description
user_id String Search by the full user ID (exact match).
short_id String Search by the user's short ID (exact match).
user_name String Search by username. Supports partial matches.
since_id Integer Messages with an ID greater than this value.
before_id Integer Messages with an ID lower than this value.
exact_id Integer Get the message with the exact id of this value.
limit Integer Number of rows to return (1-1000, default: 100).
message String Exact match of the entire message string.
message_contains String Ordered keyword search separated by ;.
message_type Integer 2 = Chat, 13 = Trade.

Response Structure

The response returns an object containing the total count and an array of message objects.

Key Type Description
count Integer The number of messages returned.
results Array A list of message objects.

Message Object Fields

Field Type Description
id Integer Unique database ID.
hash String Sha256 verification hash.
user_id String Full unique identifier for the sender.
user_short_id String Public-facing short ID.
user_name String Username at the time of recording.
user_role String Role/rank (e.g., USER, ADMIN).
user_level Integer In-game level.
message String Message content.
type Integer Channel/type (2 = Chat, 13 = Trade).
received_at String Timestamp (YYYY-MM-DD HH:MM:SS).

Endpoint: /api/stats

Retrieve global and recent chat statistics. Metrics are calculated using the most recent 60,000 messages. Cache Duration: 60 seconds.

Key Type Description
totalMessages Integer Absolute total number of messages.
sampleSize Integer Number of recent messages used for metrics.
today Object Message count for the current day.
thisHour Integer Messages sent in the last 60 minutes.
uniqueUsers Integer Total unique users in the sample.

Hash Verification Information

Hashing algorithm: Sha256

Canonical format:
prev_hash|user_id|user_short_id|user_name|user_role|user_level|message|type|received_at

All non-string values must be converted to base-10 string representation. Final string must be UTF-8 encoded.
